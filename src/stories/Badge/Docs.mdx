```
알림을 표시하는 작은 아이콘이나 배지로, 사용자가 특정 항목이나 상태에
대해 새로운 정보나 업데이트가 있음을 시각적으로 알려주는 요소입니다.
```

### 원칙
- 한 화면 내에서 여러 개의 배지를 사용할 경우 정렬을 동일하게 사용합니다.
- 여러 개의 배지를 무분별하게 사용하는 것을 지양합니다.
- 알림 배지는 매우 작고 원형입니다. 따라서 많은 콘텐츠를 담을 수 없습니다. 최대 999+까지 표시가 가능하며, 5자 이상의 단어 사용을 지양합니다.

---

# Usage

#### ✅ 사용하기 적합한 경우
- 사용자가 받은 알림의 수를 표시합니다.
- 상호작용이 필요하지 않은 간단한 정보를 보여줍니다.

#### ⛔ 부 적합한 경우
- 매우 짧은 숫자나 하나의 아이콘보다 긴 경우에는 칩을 사용하세요.
- 동작을 포함하려면, 버튼을 사용하세요.

## Type

### dot

- 새로운 업데이트가 있을 경우 점으로 표현하는 유형입니다.
- 아이콘 또는 아이콘+메뉴명과 함께 사용합니다.
- 텍스트 레이블 성격에는 사용하지 않습니다.
- 단, 최상위 탭의 레이블에서는 사용할 수 있습니다.

### number
- 서비스 항목의 업데이트 수, 새로운 알림등을 숫자로 카운팅하여 노출하는 유형입니다.
- 아이콘과 함께 사용합니다.
- 텍스트와 함께 사용하는 것을 지양합니다.

### text
- 서비스가 업데이트되거나, 새로 출시되었을 경우 텍스트로 노출하는 유형입니다.
- 텍스트와 함께 사용합니다.
- 아이콘과 함께 사용하는 것을 지양합니다.
- 축약어를 사용하지 않습니다. (ex. N)
