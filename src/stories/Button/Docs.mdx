# Usage

#### ✅ 사용하기 적합한 경우
- 주요 기능의 실행 동작을 나타냅니다.
- 액션을 충분히 뚜렷하게 보이게 해야 할 때.

#### ⛔ 부 적합한 경우
- 문단 내에 또는 목록 내의 텍스트를 작업하게 만들려면


## Type

모든 화면에는 버튼과 및 상호 작용 구성 요소의 명확한 시각적 계층 구조로 나뉩니다.<br />
계층 구조의 모든 단계를 사용할 필요는 없습니다. 화면 맥락에서 필요하지 않다면 레벨을 건너뛸 수 있습니다.

### 1. Primary
- 브랜드의 핵심 가치를 전달, 서비스의 주료 기능에 사용합니다.
- CTA에 적합하며, 1화면에 1개만 사용하는 것을 권장합니다.

### 2. Critical
- 삭제나 초기화 같은 파괴적이거나 부정적인 액션에 사용되며, 사용자에게 경고하는 메시지를 전달합니다.

### 3. Secondary
- primary 다음으로 높은 위계를 가지며, 대부분의 화면에서 CTA로 사용합니다. <br/>
- primary와 달리, 브랜드 아이덴티티를 전달하지 않으며, 1화면에 1개만 사용하는 것을 권장합니다.

### 4. White → Neutral Outline
- 덜 중요한 서비 액션에 사용되며, 시각적 부담이 적습니다. <br/>
- CTA에서 조합될 경우, primary와 secondary를 보조하는 역할을 합니다. <br/>
- *보다 직관적이게 white에서 neutral outline으로 이름 변경

### 5. Secondary Text
- 가장 낮은 위계. 여러 동작들이 필요할때 사용.

# Property

### Size

정렬은 큰 사이즈 → 작은 사이즈

- xl
- lg
- md
- sm (pill, round 형태로 바꾸는게 좋을까 고민됨)

### Width

컨테이너 너비를 가득 채우거나, 콘텐츠에 맞는 크기로 조정.

- 최대 너비
- 최소 너비

### Layout

아이콘 유무

- none
- iconLeft
- iconRight
- iconOnly
- both (비포함 고려. 사용률 낮을때 제거.)
